# 📖 Overview

Sketch2Code AI is an AI-powered educational platform that bridges the gap between algorithm design and programming.

Students, teachers and developers can create flowcharts using a digital pen or mouse, recognize hand-drawn sketches using AI, convert them into clean flowcharts, generate executable code, simulate execution, analyze complexity, detect logical errors and collaborate in real time.

The project was designed as a complete Software Engineering solution with modern frontend architecture, scalable backend APIs and Artificial Intelligence integration.

# 🚀 Installation

## Clone Repository

```bash
git clone https://github.com/adityaraj-projects/Sketch2Code-AI.git

cd Sketch2Code-AI
```

---

## Backend

```bash
cd backend

python -m venv venv

venv\Scripts\activate

pip install -r requirements.txt

uvicorn app.main:app --reload
```

---

## Frontend

```bash
cd frontend

npm install

npm run dev
```
